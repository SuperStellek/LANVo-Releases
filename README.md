# LANVo downloads

Windows installers for LANVo, a peer-to-peer LAN voice chat and audio sharing app.

Download **LANVo-Setup-win-x64.exe** from [Releases](https://github.com/SuperStellek/LANVo-Releases/releases). Run it to install LANVo. Windows requests administrator approval; installers are currently unsigned.

This repository distributes installers and SHA-256 checksums only. Source code stays in a separate repository. No private keys or access tokens are distributed here.

LANVo checks this repository for updates at startup and asks before installing one.

[Download the latest Windows installer](https://github.com/SuperStellek/LANVo-Releases/releases/latest/download/LANVo-Setup-win-x64.exe).
